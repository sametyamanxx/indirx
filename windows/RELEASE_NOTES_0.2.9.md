# İndirX Windows 0.2.9

- İndirmeler bölümü sol sütunda Bağlantı ekle bölümünün hemen altına taşındı. Sağdaki tercih panelinin yüksekliğinden kaynaklanan boşluk kaldırıldı.
- İki sütun bağımsız dikey akış kullanır. Altyapı güncelleme düğmesi sağda tercihlerin altında kalır. Bulunan içerikler gösterildiğinde sol sütundaki öğeler sırasıyla aşağı kayar, üst üste binmez.
- Android logosu, ortalı başlık, koyu pencere çubuğu, yalnızca YouTube/Instagram desteği ve oturumluk geçmiş davranışı korunur.
- Sağ panel büyütüldüğünde İndirmeler bölümünün aşağı itilmediğini ve bulunan içeriklerin akışta kaldığını denetleyen arayüz regresyon kontrolleri eklendi.

Windows 10 22H2 / Windows 11 x64. Önceki Windows sürümüyle aynı kurulum kimliği kullanılır; uygulamayı kapatıp aynı konuma kurarak güncelleyebilirsiniz. Tercihler ve medya dosyaları korunur. Setup/EXE dijital imzasızdır; SmartScreen uyarısı görülebilir. Gerçek platform indirmeleri bu yerleşim güncellemesi için ayrıca test edilmemiştir. Android APK 0.2.7 değişmedi.
