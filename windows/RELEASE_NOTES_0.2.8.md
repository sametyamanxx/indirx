# İndirX Windows 0.2.8

- Android uygulamasındaki logo, mevcut vektör dosyasından değiştirilmeden Windows simgelerine ve arayüz görseline dönüştürüldü.
- Program, Setup, kurulum sihirbazı, Başlat menüsü/masaüstü kısayolları, pencere ve görev çubuğu simgeleri aynı markayı kullanır.
- Üst ortada logo; hemen altında ortalı İNDİRX. İlk satırda solda Bağlantı ekle, sağda İndirme tercihleri. Alt satırda solda İndirmeler, sağda İndirme altyapısını güncelle.
- Kayıt klasörünü aç düğmesi ve işlevi kaldırıldı. Kayıt klasörünü seç korunur.
- Beyaz yerel başlık çubuğu yerine koyu başlık çubuğu etkinleştirildi; Windows 11'de tema renkleri de uygulanır.
- Yalnızca YouTube/Instagram desteği ve kalıcı indirme geçmişi tutmama davranışı korundu. Android APK 0.2.7 değiştirilmedi.

Windows 10 22H2 / Windows 11 x64. .NET, yt-dlp, FFmpeg ve Deno paketlidir. Aynı kurulum kimliğiyle önceki Windows sürümünün bulunduğu konuma güncelleme kurulabilir. Medya dosyaları ve tercihler silinmez. Eski sabitlenmiş kısayollar Windows simge önbelleği nedeniyle yeniden sabitleme gerektirebilir.

Setup/EXE dijital imzalı değildir; SmartScreen uyarısı görülebilir. Gerçek YouTube/Instagram video indirmeleri bu tasarım değişikliği için ayrıca test edilmemiştir.
