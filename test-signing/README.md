İmzalama anahtarı Git deposuna eklenmez. Android 0.2.10'dan itibaren CI, ANDROID_SIGNING_KEYSTORE ve ANDROID_SIGNING_PASSWORD GitHub Actions secrets değerlerinden kalıcı PKCS12 anahtarını geçici olarak geri yükler. Gradle, INDIRX_SIGNING_STORE ve INDIRX_SIGNING_PASSWORD ortam değişkenleriyle bu anahtarı kullanır (alias: indirx). Anahtar ve şifrenin güvenli, depo dışı yedeğini saklayın; anahtarı değiştirmek mevcut kullanıcıların üzerine güncellemesini engeller. Yerel testte ortam değişkenleri yoksa indirx-debug.keystore veya varsayılan debug anahtarı kullanılır; bu yerel APK yayımlanan APK ile imza uyumlu olmayabilir. 0.2.9 ve önceki imzası farklı test APK'ları ilk geçişte elle kurulum gerektirebilir.
